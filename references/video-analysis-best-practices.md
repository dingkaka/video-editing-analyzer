# 视频分析方法与证据规则

## 文件职责

本文件只回答两件事：

1. 怎样从视频或截图中提取可靠的剪辑信息。
2. 怎样区分明示事实、合理推断和无法判断。

具体剪映功能查 `jianying-features.md`，音效/BGM 资源查
`music-sfx-resource-library.md`，人声处理查
`voice-and-audio-guide.md`，逐句输出格式查
`sentence-shot-template.md`。

## 先判断输入类型

| 输入 | 分析重点 | 默认忽略 |
|------|----------|----------|
| 剪辑教程/拆解视频 | 参数面板、功能名、时间线、标注、前后对比 | 教程自身 BGM、普通口播字幕、平台 UI |
| 教程截图 | 画面文字、功能区域、轨道结构、案例时间码 | 点赞数、手机时间、无关装饰 |
| 普通成片/参考视频 | 结构、节奏、画面、字幕、声音的可观察特征 | 无证据的具体功能名和参数 |
| 用户文案 | 内容结构、逐句画面与声音设计 | 不相关的教程分析流程 |

教程视频与普通成片不能使用同一判断标准。教程画面显示的功能名可以记录为
“画面明示”；普通成片只展示结果，通常只能给出一种或多种可能实现方式。

## 教程视频读取流程

### 1. 建立素材清单

- 记录文件名、总时长、分辨率、帧率和是否含音轨。
- 视频可访问时，优先运行 `scripts/extract_video_keyframes.py`。
- 截图按文件名或用户给出的编号排序；不能确认顺序时明确说明。

### 2. 关键帧采样

至少覆盖以下位置：

- 教程标题、章节切换和步骤总结。
- 参数面板、搜索结果、效果名称特写。
- 时间线停留画面、轨道展开画面和关键帧界面。
- 操作前后对比、预览结果和失败示范。
- 画面中文字发生明显变化的位置。

固定间隔帧用于防漏，场景切换帧用于发现新步骤。连续帧表达同一信息时，只保留
最清晰且字段最完整的一张。

### 3. 分区读取

对分屏、录屏或套壳画面分开记录：

- **平台层**：作者名、点赞数、进度条等，只用于定位来源。
- **教程标注层**：箭头、框选、步骤文字、音效名等，通常是高价值信息。
- **软件界面层**：菜单、参数、轨道、时间码和操作路径。
- **案例画面层**：被拆解视频的实际效果。

不要把教程视频的播放进度，误写成软件时间线里的案例时间码。

### 4. 必要时再听音频

只有以下情况需要转录：

- 关键参数只在口播中说出。
- 画面步骤省略，需要口播补足因果关系。
- 用户明确要求分析教程讲解、声音或 BGM。

先定位相关时间段，再做局部转录；无需默认转录整段教程。

## 证据分级

| 等级 | 定义 | 可否写成确定事实 |
|------|------|------------------|
| 画面明示 | 界面直接显示名称、参数、路径或时间线 | 可以，但只代表教程确实这样展示 |
| 口播明示 | 教程作者明确说出名称、参数或步骤 | 可以，但需标注“口播说明” |
| 视觉推断 | 根据成片外观推测实现方式 | 不可以，必须写“可能/疑似”并标置信度 |
| 无法判断 | 画面模糊、证据冲突或关键信息缺失 | 不得补全 |

### 三种置信度不要混用

- **OCR 置信度**：画面文字是否读清楚。
- **实现方式置信度**：推测的功能是否可能产生该效果。
- **来源可靠性**：教程说法是否经过验证、是否受版本限制。

画面清楚不等于教程结论可靠；效果高度相似也不等于能确定具体功能。

## 单条事实记录格式

每个候选知识点先保存以下字段：

| 字段 | 记录要求 |
|------|----------|
| 来源位置 | 教程时间点、时间段或截图编号 |
| 案例时间码 | 软件界面里显示的原案例时间；未显示则写“未显示” |
| 原始文字 | 尽量保留界面原文；模糊处写 `[疑似：…]` |
| 观察结果 | 画面发生了什么变化 |
| 功能/手法 | 明示则照录；推断则列备选 |
| 参数 | 只记录显示或明确说出的数值 |
| 证据类型 | 画面明示 / 口播明示 / 视觉推断 |
| 置信度 | 高 / 中 / 低，并说明理由 |
| 来源可靠性 | 已验证 / 教程单一来源 / 待验证 |

同一知识点跨多帧出现时合并证据，不要生成多条近义记录。

## 普通成片拆解流程

### 1. 先做结构分段

按内容功能划分钩子、铺垫、主体模块、转折、总结和行动引导。分段边界应来自
台词主题变化、画面切换、音乐变化或明显停顿，而不是套固定秒数。

### 2. 再看可观察层

- **画面**：景别、构图、主体位置、素材类型、画中画和运动方向。
- **文字**：字幕层级、重点词、颜色、位置、出现时机和动画外观。
- **节奏**：镜头长度、切点密度、停顿、快慢变化和重复结构。
- **声音**：人声、BGM、环境音和强调音效之间的关系。
- **衔接**：硬切、遮挡切、动作匹配、声音先行或画面先行。

### 3. 计算而不是凭感觉

- 平均镜头时长 = 有效时长 ÷ 镜头数。
- 切换密度 = 切点数 ÷ 有效时长。
- 语音停顿只记录明显且影响剪辑的停顿。
- 卡点判断需要对照可听见的节拍与切点；只能确认“对齐”，不能据此确认使用了
  “自动踩点”。

### 4. 输出复现方案

把观察结果转成可执行动作，同时保留不确定性：

- 已确认外观：写明视觉或听觉结果。
- 可能实现：列 1-3 种候选功能或手工方法。
- 参数未知：给测试范围或调节方向，并标注“建议值”，不能伪装成原片参数。

## 常见推断边界

| 观察结果 | 可以说 | 不可以直接说 |
|----------|--------|----------------|
| 字幕与口播同步 | 字幕同步准确 | 一定用了 AI 字幕 |
| 切点贴合节拍 | 画面在节拍处切换 | 一定用了自动踩点 |
| 画面平滑缩放 | 可能使用关键帧或预设动画 | 一定用了某个指定特效 |
| 局部区域模糊 | 可能使用蒙版、跟踪或局部特效 | 一定使用某个固定功能 |
| 人声更干净 | 可能做了降噪、EQ 或重新录音 | 一定开启了剪映降噪 |

功能名称、菜单路径和素材库名称可能随版本、设备和地区变化。未在教程中明示时，
使用描述性名称比猜一个产品功能名更可靠。

## 长视频处理

- 先按章节或主题分段，再在每段内抽取关键画面。
- 对参数密集片段提高抽帧频率，不对全片无差别逐帧分析。
- 先输出章节级知识清单，用户需要时再展开单个步骤。
- 超过一次可处理范围时，说明已覆盖和未覆盖的时间段。

## 失败与冲突处理

- OCR 模糊：保留原图位置和疑似文字，请用户补高清截图。
- 画面与口播冲突：并列记录两种说法，不代替用户选边。
- 不同版本路径冲突：记录教程版本或界面特征，路径写成版本相关。
- 缺少视频文件：说明无法运行抽帧，直接分析已有截图或文本。
- FFmpeg 不可用：回退到平台自带取帧能力或请用户补关键帧。

## 输出路由

- 教程/拆解视频：使用 `SKILL.md` 的“教程知识卡片”。
- 普通参考成片：输出结构分段、可观察特征、可能实现和复现建议。
- 用户文案：使用 `sentence-shot-template.md` 的逐句两列表格。
- 学习请求：只输出候选知识；用户确认后才写入
  `learned-editing-knowledge.md`。
