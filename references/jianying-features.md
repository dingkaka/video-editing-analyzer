# 剪映功能识别速查

## 文件职责

本文件只提供剪映功能类别、可观察特征和识别边界。它不是完整操作手册，也不负责
推荐音效/BGM、音频参数或输出模板。

> 功能名称、素材名称和菜单路径会随剪映版本、设备、会员状态和地区变化。只有教程
> 画面或口播明确显示时，才把具体名称和路径写成确定事实。

## 识别总原则

1. 先记录“看到的效果”，再匹配“可能的功能”。
2. 界面明示优先于外观推断。
3. 一个效果可能有多种实现方式，未明示时列备选。
4. 参数只照录画面或口播出现的值；经验值必须标注为建议。
5. 不能从成片外观确认是否使用 AI、模板或自动化功能。

## 音乐与节拍

| 功能类别 | 可观察特征 | 识别边界 |
|----------|------------|----------|
| 背景音乐轨 | 时间线上存在持续音频轨，可能有分割和音量曲线 | 只能判断存在音乐，不能确认素材库名称 |
| 淡入淡出 | 音量在片头或片尾连续变化 | 也可能由关键帧或外部软件完成 |
| 节拍标记 | 时间线上显示节拍点或教程明确演示标记操作 | 成片卡点不能证明使用自动踩点 |
| 自动踩点 | 界面或口播明确出现“自动踩点” | 仅凭切点准确不得确定 |

## 音效

| 类型 | 可观察特征 | 常见用途 |
|------|------------|----------|
| 转场音效 | 短促、与画面切换同步 | 加强速度和方向感 |
| 强调/点击音 | 与文字、图标或数据出现同步 | 突出信息节点 |
| 环境音 | 持续时间较长、音量较低 | 补充场景真实感 |
| 拟音 | 与动作发生时刻同步 | 强化触感、碰撞或操作反馈 |

具体资源名称和搜索词见 `music-sfx-resource-library.md`。

## 画面与合成

| 功能类别 | 可观察特征 | 可能的其他实现 |
|----------|------------|----------------|
| 滤镜/调色 | 全画面色彩、对比度、饱和度或色温变化 | LUT、手动调色、拍摄时布光 |
| 关键帧 | 位置、缩放、旋转或透明度随时间连续变化 | 预设动画、运镜素材 |
| 画中画 | 多个画面同时存在、轨道叠放 | 拼图模板、合成素材 |
| 蒙版 | 效果只作用于局部或有明确形状边界 | 已处理好的素材、局部特效 |
| 抠像 | 主体与新背景合成，边缘可能有抠图痕迹 | 绿幕、智能抠像、外部合成 |
| 跟踪 | 文字、贴纸或遮挡物持续跟随主体 | 手动关键帧、智能跟踪 |
| 定格 | 某一帧停留，声音可继续 | 截图回填、速度设为零 |
| 变速 | 动作速度改变，可能伴随节奏变化 | 曲线变速、普通倍速、抽帧 |
| 倒放 | 动作方向与因果顺序反转 | 原素材本身倒序拍摄 |

### 常见视觉效果描述

- 模糊：高斯模糊、动态模糊、径向模糊等外观。
- 缩放：推近、拉远、呼吸缩放或冲击缩放。
- 抖动：规则节拍抖动、随机手持感或冲击震动。
- 故障风：RGB 分离、错位、撕裂和信号干扰。
- 光效：闪白、闪光、光晕、粒子和曝光变化。

未显示具体名称时，优先使用上述描述性词语。

## 文字与字幕

| 功能类别 | 可观察特征 | 识别边界 |
|----------|------------|----------|
| 基础字幕 | 字体、字号、颜色、位置、描边和阴影 | 字体外观相似时不要强猜字体名 |
| 重点词强调 | 局部变色、放大、加粗或独立成行 | 可能是手工拆分文本 |
| 入场/出场动画 | 淡入、滑入、缩放、弹跳等 | 可能来自关键帧或预设 |
| 逐字出现 | 文字按字符或词组依次出现 | 只能描述为打字机式外观 |
| 自动字幕 | 界面或口播明确演示语音识别生成 | 同步准确不能证明使用自动字幕 |
| 文本朗读 | 界面显示音色选择或生成的独立音轨 | 仅听声音不能可靠确定音色名称 |

字体名、音色名和模板名只在画面可辨认时照录；OCR 模糊时使用
`[疑似：名称]`。

## 转场

| 外观 | 描述 | 可能实现 |
|------|------|----------|
| 硬切 | 前后镜头无过渡直接切换 | 普通分割 |
| 叠化 | 两画面短暂重叠、透明度交替 | 叠化转场或手动透明度 |
| 闪黑/闪白 | 切点出现短促黑场或白场 | 转场、色块或曝光关键帧 |
| 推拉/缩放 | 新旧画面沿方向移动或缩放替换 | 转场预设或关键帧 |
| 模糊 | 切点前后模糊再恢复 | 模糊转场或手动叠加特效 |
| 遮挡切 | 物体经过镜头时完成切换 | 蒙版、匹配剪辑或实拍遮挡 |
| 动作匹配 | 前后镜头保持相似动作和方向 | 人工选点为主，不一定使用转场 |

记录转场时至少写：位置、持续时间、运动方向、是否伴随音效。无法辨认具体名称时，
只写外观和复现方向。

## 时间线与轨道

教程画面出现时间线时，优先读取：

- 主视频轨、画中画轨、文字轨、贴纸/特效轨和音频轨的层级。
- 素材边界、重叠区、关键帧标记、变速区域和音量曲线。
- 效果覆盖范围与前后素材的关系。
- 软件时间码与教程播放器时间码。

轨道层级只能证明项目结构，不能自动证明最终导出时使用了某个模板或 AI 功能。

## AI、模板和自动化功能

以下功能只有在界面或口播明示时才能确认：

- AI 字幕、文本朗读、智能抠像。
- 自动踩点、智能剪辑、一键成片。
- AI 配乐、智能推荐、画质增强。
- 模板套用、风格迁移或自动包装。

如果未明示，输出格式应为：

> 画面表现为……；可能通过 A、B 或手工 C 实现。当前无法从成片确认具体功能。

## 版本记录建议

当教程依赖具体界面路径时，额外记录：

- 教程发布日期或用户提供的版本信息。
- 桌面版/移动版、Windows/macOS/iOS/Android。
- 菜单文字和界面截图。
- 是否显示会员、地区限定或联网素材标识。

不要把旧教程中的路径改写成当前路径，也不要假设不同平台功能完全一致。
