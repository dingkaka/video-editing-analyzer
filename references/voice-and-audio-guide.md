# 人声与音频处理指南

## 文件职责

本文件只处理人声判断、录音问题、降噪、EQ、压缩、响度和混音。音效/BGM 的搜索词
与素材选择见 `music-sfx-resource-library.md`。

> 下列数值是常见起点，不是剪映固定参数，也不是所有声音的标准答案。先听原素材，
> 再小幅调整和对比旁路效果。

## 分析顺序

1. **内容清晰度**：是否听得清每个字，有无爆音、底噪、混响和齿音。
2. **音色特征**：偏厚、偏薄、偏亮、偏暗、偏鼻或偏闷。
3. **动态**：音量是否忽大忽小，重音是否仍自然。
4. **空间**：声音是贴近、干燥，还是有明显房间反射。
5. **混音关系**：人声是否始终压过 BGM 和环境声。

不要根据主播性别、服装或画面风格反推音色处理；以实际声音为准。

## 常见人声问题

| 问题 | 可听特征 | 优先处理 |
|------|----------|----------|
| 持续底噪 | 无人说话时仍有风扇、电流或空调声 | 轻度降噪、门限或重录 |
| 房间混响 | 尾音拖长、声音离麦克风很远 | 改善录音环境、去混响或重录 |
| 低频轰鸣 | 声音浑浊、桌面震动、空调低鸣 | 高通滤波 |
| 鼻音/箱体感 | 中低频拥挤，像在箱子里 | 小幅削减问题频段 |
| 清晰度不足 | 辅音不清、声音被音乐盖住 | 调整混音，再小幅增强存在感 |
| 齿音刺耳 | “s、sh、z”过亮 | De-esser 或轻削高频 |
| 爆破音 | “p、b”出现低频冲击 | 修剪、自动化或高通 |
| 音量起伏大 | 轻声听不清、重声过响 | 手动音量自动化后再压缩 |
| 削波失真 | 峰值破裂、声音粗糙 | 无法完全修复，优先重录 |

## 处理链

推荐顺序不是强制，但适合多数口播：

1. 修剪无用片段、口水音和明显爆点。
2. 轻度降噪或去混响。
3. 高通和减法 EQ。
4. 压缩或音量自动化。
5. 必要的加法 EQ、De-esser。
6. 限幅与最终响度检查。

处理前后要以相近听感音量做 A/B 对比，否则“更响”容易被误判为“更好”。

## 降噪

- 只处理确实存在的噪声，不默认开启重度降噪。
- 从最低有效强度开始；出现水下感、金属感或尾音断裂时立即回退。
- 稳定底噪比随机碰撞声更适合自动降噪。
- 严重混响、风噪或削波通常无法靠单一开关修好，重录更可靠。
- 教程只显示“轻度/中度/重度”时照录档位，不换算成虚构数值。

## EQ 起点

| 目标 | 常见操作起点 | 注意 |
|------|--------------|------|
| 去轰鸣 | 约 70-100 Hz 高通 | 低沉人声切得过高会变薄 |
| 减少浑浊 | 约 150-350 Hz 小幅削减 | 先扫频定位，不要整段大削 |
| 增加清晰度 | 约 2-5 kHz 小幅调整 | 过多会刺耳、疲劳 |
| 增加空气感 | 约 8-12 kHz 轻微提升 | 底噪和齿音也会被放大 |
| 控制齿音 | 约 5-9 kHz 动态衰减 | 因人而异，优先用 De-esser |

EQ 建议以 1-3 dB 的小幅动作开始。除非有明确测量和试听依据，不直接套用大幅增益。

## 压缩

口播的目标是稳定可懂，不是把动态完全压平。

可作为起点：

- Ratio：约 2:1 到 4:1。
- Attack：约 10-30 ms，保留适量辅音和重音。
- Release：约 60-200 ms，跟随语速调整。
- Threshold：按素材电平设定，让常规语句产生温和增益衰减。
- Makeup gain：只补回被压低的听感音量，防止削波。

若呼吸声和底噪被明显抬高，先降低压缩量或处理噪声，不要继续堆限制器。

## 音量与响度

- 人声是口播视频的基准层，BGM 和音效围绕它调整。
- 峰值不等于响度；发布前同时检查短时听感、整体响度和真峰值。
- 平台会进行不同程度的响度处理，不承诺一个数值适用于所有平台。
- 没有响度表时，至少在耳机、手机扬声器和低音量播放下检查可懂度。
- 给最终编码保留真峰值余量，常用起点可设在约 -1 dBTP 或更低。

当用户明确要求交付规格时，再按目标平台当时的官方要求核验，不把经验值写成平台
硬性标准。

## BGM 与人声混合

- 先把人声调到稳定、清晰，再加入 BGM。
- BGM 有歌词或中频密集时，比纯器乐更容易遮挡口播。
- 重点语句可用音量自动化或 ducking 临时压低音乐。
- 不同 BGM 母带响度差异很大，不能用同一“百分比”直接复用。
- 转场音效短暂超过人声并非绝对错误，但不能掩盖关键信息。

## 录音阶段

- 麦克风与嘴保持稳定距离和角度，使用防喷罩。
- 关闭可控噪声源，减少硬墙反射，录一段环境底噪备用。
- 电平以最激烈一句仍不削波为准。
- 分段录音时保持设备、距离和房间状态一致。
- 对严重错误优先补录，不把后期处理当作无限修复。

## 风格匹配

| 内容目标 | 人声倾向 | 处理重点 |
|----------|----------|----------|
| 知识/教程 | 清晰、稳定、靠前 | 可懂度、动态稳定、少混响 |
| 情感/故事 | 自然、温暖、有起伏 | 保留动态和呼吸，不要压得太平 |
| 搞笑/吐槽 | 明亮、节奏清楚 | 重音、停顿和音效空间 |
| 商业/产品 | 干净、可信、统一 | 录音一致性、峰值和响度控制 |
| 沉浸/ASMR | 近距离、细节丰富 | 极低噪声、齿音和瞬态控制 |

## 诊断输出格式

分析用户音频时按以下顺序给建议：

1. **可听问题**：只写实际听到或测到的现象。
2. **优先级**：先修影响可懂度的问题。
3. **处理动作**：给功能和方向，必要时给起始范围。
4. **副作用**：说明过量处理会发生什么。
5. **验证方法**：旁路对比、不同设备试听和响度/峰值检查。

无法访问原音频时，不声称已诊断；只能给条件式建议。

## 完成前检查

- [ ] 人声全程清晰，重音和情绪仍自然。
- [ ] 降噪没有水下感、金属感或断尾。
- [ ] EQ 没有让声音明显变薄或刺耳。
- [ ] 压缩没有持续抽吸，也未把底噪抬高。
- [ ] BGM 和音效没有遮挡关键信息。
- [ ] 最终输出无削波，并在至少两种播放设备上试听。
