# 口播文案逐句剪辑方案模板

## 文件职责

本文件规定“用户给文案后”的输出格式。完整成品示例见
`example-jianying-skill-intro.md`，不要在本文件重复示例内容。

## 使用条件

- 适用于口播、知识分享、工具介绍、好物推荐和教程讲解。
- 按语义停顿拆句，不机械按标点拆。
- 用户只问某一句或某一段时，只输出对应卡片。
- 用户要求完整方案时，才输出整体定位、钩子、全部分句、时间轴和注意事项。

## 一、视频基本信息

| 项目 | 内容 |
|------|------|
| 主题 | 视频核心主题 |
| 风格 | 知识/工具/经验/推荐/故事等 |
| 预计时长 | 按文案和语速估算 |
| 情绪基调 | 整体情绪和主要变化 |
| 目标平台 | 用户指定；未指定则写“待确认” |
| 语速参考 | 估算值或用户指定值 |

## 二、整体定位与情绪

### 内容定位

用 2-3 句话说明目标受众、核心价值和观看理由。

### 情绪曲线

```text
情绪强度
  高 ↑    ╭──╮       ╭───╮
     │   ╱    ╲     ╱     ╲
  中 ├──╯──────╲───╯───────╲─
  低 ↓──────────╰────────────╰─
          开场    主体/转折    收尾
```

根据实际内容标注节点，不套固定秒数。

### 整体策略

- **节奏**：说明快慢变化和停顿安排。
- **视觉**：说明主播、录屏、B-roll、图表和文字卡片的关系。
- **声音**：说明人声、BGM、音效和留白的关系。
- **核心手法**：只列与这条文案直接相关的 3-5 条。

## 三、开场 3 秒

| 项目 | 设计 |
|------|------|
| 画面 | 第一帧和前 3 秒画面变化 |
| 台词 | 实际开场台词，不擅自改写时标注“建议改写” |
| 字幕 | 标题、重点词、位置和动画 |
| 音效 | 名称/搜索词、入点；不需要写“无” |
| BGM | 直接起、淡入、压低或前段留白 |
| 镜头 | 景别、运动和切换 |
| 情绪目标 | 好奇、共鸣、惊讶、信任等 |

补一句“为什么这样设计”，不能只写“抓住注意力”。

## 四、逐句剪辑

**禁止把所有句子放进一个横向大表格。每句话必须独立使用以下卡片：**

---

### 📌 第1句：（简短句意或原句）

> **文案**：（完整台词）

| 项目 | 建议 |
|------|------|
| **画面** | 主画面、B-roll、录屏、图表或文字卡片的具体安排 |
| **字幕** | 基础样式、重点词、位置、出现方式 |
| **音效** | 音效名称/搜索词、入点和用途；不需要写“无” |
| **BGM** | 此句的情绪、音量关系和变化 |
| **镜头** | 景别、固定/推/拉/摇/移或切换方式 |
| **时长** | 约 X 秒，包含必要停顿 |
| **表情/语气** | 表情、语速、重读、停顿和动作 |
| **可选补充** | 仅写本句特有的转场、素材或操作提醒；没有则删除 |

---

下一句继续使用同样的独立两列表格，直到文案结束。

## 五、完整时间轴

时间轴用于检查整体结构，可以使用汇总表，但不能替代逐句卡片。

| 时间段 | 内容模块 | 核心动作 | 情绪 | 节奏 |
|--------|----------|----------|------|------|
| 0:00-0:03 | 钩子 | 第一观看理由 | 高 | 快/留白 |
| … | 按实际文案填写 | 画面或声音变化 | … | … |

各句时长之和必须与时间轴和预计总时长基本一致。

## 六、制作注意事项

只写当前方案真正会影响执行的内容：

- **节奏**：切点、句间停顿、需要留白的位置。
- **字幕**：统一字体、颜色用途、安全区和重点词比例。
- **音频**：人声优先、BGM 变化、音效密度和异常处理。
- **视觉**：主体位置、素材风格、转场上限和色彩统一。
- **易错点**：当前文案最容易剪错的 3-5 项。

不要写“注意节奏”“适当加特效”等空泛提醒。

## 填写规则

### 画面

- 优先选择能解释本句含义的画面，而不是只追求好看。
- 信息密度高时用录屏、步骤卡或图表；情绪句可保留主播表演。
- 素材不存在时写素材需求，不假装用户已有。

### 字幕

- 基础字幕保持统一，重点词才变色、放大或独立成行。
- 字体名不确定时描述外观，不强猜具体名称。
- 避免遮脸和平台 UI；用户未给画幅时不要写死像素位置。

### 音效与 BGM

- 音效只放在钩子、转折、结论或明确动作点。
- 不连续使用同一种提示音。
- BGM 变化服务情绪和信息层级，不因每句换歌。
- 具体资源名无法确认时给搜索关键词。

### 镜头与时长

- 切换依据是语义、动作和注意力节点，不机械每句都切。
- 长句可拆成同一卡片内的画面 A/B，不必把语义拆碎。
- 时长按实际字数、语速、停顿和画面阅读时间估算。

### 表情与语气

- 写可执行动作：停顿 0.3 秒、重读某词、前倾、看向屏幕。
- 不只写“自然”“有感染力”等抽象词。

## 已学知识调用

生成前检索 `learned-editing-knowledge.md`：

- 只使用与内容类型、平台、时长和风格匹配的已确认条目。
- 待验证条目只能作为可选方案。
- 不为展示知识库而强行加入不相关技巧。
- 完整文档末尾列出“本次调用的已学知识”；没有匹配项则省略。

## 输出检查

1. 每句都有独立标题和“项目/建议”两列表格。
2. 没有用一个横向大表格代替逐句方案。
3. 画面、字幕、音效、BGM、镜头、时长、表情/语气均已填写。
4. 建议与台词含义对应，不是重复套话。
5. 参数区分教程明示值与建议值。
6. 总时长、逐句时长和时间轴基本一致。
7. 完整方案包含开场钩子、情绪曲线和针对性注意事项。
