# 音效、BGM 与配音资源速查

## 文件职责

本文件只用于选择和搜索声音资源：音效类型、BGM 方向、配音音色关键词和版权检查。
人声降噪、EQ、压缩和响度处理见 `voice-and-audio-guide.md`。

> 素材库内容会随版本、地区、账号和授权状态变化。资源名称只能作为搜索词；使用前
> 必须在当前平台确认是否存在、是否收费以及授权范围。

## 音效选择原则

1. 先确定声音承担的功能：强调、转场、动作反馈、环境或情绪。
2. 优先搜索声音特征，不依赖单一素材名。
3. 音效入点要对齐画面事件，长度只覆盖动作所需时间。
4. 人声信息密集处少加音效；同一节点通常只保留一个主音效。
5. 音量先从低处试，再按实际素材和监听设备调整。

## 场景与搜索词

| 用途 | 可搜索关键词 | 适合画面 | 使用提醒 |
|------|--------------|----------|----------|
| 快速切换 | 咻、whoosh、swipe、快门 | 快切、滑动、推拉 | 注意方向感和切点 |
| 平滑过渡 | 风、soft whoosh、air、过渡 | 叠化、模糊、慢推 | 不要比人声更抢 |
| 信息强调 | 叮、click、pop、提示、确认 | 关键词、数字、按钮 | 对齐文字出现瞬间 |
| 冲击强调 | hit、impact、boom、重击 | 反转、结论、大标题 | 低频过强会压人声 |
| 搞笑反差 | 尴尬、乌鸦、弹簧、摔倒、笑声 | 吐槽、失误、反转 | 依内容调节夸张度 |
| 科技反馈 | digital、scan、beep、UI、科技 | AI、软件操作、数据 | 连续使用容易疲劳 |
| 办公环境 | 键盘、鼠标、办公室、空调 | 职场、录屏、效率工具 | 作为底层环境声 |
| 自然环境 | 雨、风、鸟、街道、咖啡馆 | Vlog、故事、治愈 | 需要与画面空间匹配 |
| 动作拟音 | tap、drop、paper、cloth、step | 手势、拿放、翻页、脚步 | 声音质感要贴合物体 |

### 音效组合上限

- 常规口播：环境底声可选，重点节点再加单次音效。
- 连续三句都加同类提示音时，通常应删掉至少一处。
- 转场音效和强调音效同时出现时，确定哪一个是主声音，避免堆叠。
- 声音是否自然比“音量百分比”更重要，不使用固定百分比套所有素材。

## BGM 方向

| 内容类型 | 情绪方向 | 搜索关键词 | 节奏建议 |
|----------|----------|------------|----------|
| 知识教学 | 清晰、稳定、轻推进 | tutorial、light tech、lo-fi、知识 | 节拍稳定，少旋律抢占 |
| AI/科技 | 现代、简洁、未来感 | technology、digital、future、ambient | 留出人声频段 |
| Vlog/生活 | 自然、松弛、轻快 | vlog、daily、acoustic、chill | 与环境声协调 |
| 情感/故事 | 温暖、克制、渐进 | warm、piano、story、emotional | 转折处可升降能量 |
| 搞笑/吐槽 | 轻巧、反差、停顿感 | comedy、quirky、funny、cartoon | 为包袱留停顿 |
| 产品展示 | 精致、节奏明确 | product、fashion、minimal beat | 切点可贴节拍 |
| 高燃/卡点 | 强拍、上升、冲击 | epic、sport、bass、beat、DJ | 先标节拍再排镜头 |

### BGM 使用

- 有人声时，以不影响每个字的清晰度为最低要求。
- 开头、段落转折和结尾可用音量曲线改变能量，不必频繁换歌。
- 需要突出一句话时，可以短暂压低或停掉 BGM。
- 选择带歌词的音乐时，检查歌词是否与口播争夺注意力或产生语义冲突。
- 不把流行曲名当成长期固定推荐，优先记录风格和搜索关键词。

### 选用规则

- 先试听完整一句，检查断句、重音、多音字和情绪是否自然。
- 倍速按文案实际节奏微调，不把示例倍速当成固定参数。
- 专业内容避免过强角色化；搞笑内容也要保证关键信息听清。
- 同一角色尽量保持音色、语速和处理一致。

## 快速搭配

| 画面节点 | 声音建议 |
|----------|----------|
| 第一帧问题/结论 | 直接开口，或一个短促提示/冲击音 |
| 软件按钮点击 | click、tap、UI beep |
| 页面滑动/镜头横移 | 带方向的 whoosh/swipe |
| 大数字或关键词弹出 | pop、ding、impact 三选一 |
| 段落切换 | 轻过渡音，或只用 BGM 变化 |
| 情绪反转 | BGM 短停、低频 hit 或留白 |
| 结尾行动引导 | 轻确认音，BGM 自然收束 |

## 版权与授权检查

“平台内可用”不等于“所有用途可商用”。发布前逐项确认：

- 使用账号、地区和平台是否在授权范围内。
- 是否仅限平台内发布，跨平台是否需要另行授权。
- 商业广告、品牌合作、直播、二创和付费内容是否允许。
- 是否需要署名、购买许可证或保留授权凭证。
- 下载后离线使用、导出后再编辑是否受限。

无法确认授权时，不写“版权免费”或“可商用”，改写为“授权状态待核验”，并提供
无版权风险更低的替代方向，如平台明确标注的商用库、已购授权库或原创声音。

## 常见问题

### 人声被盖住

- 降低 BGM 和持续环境声。
- 把强调音避开关键信息音节。
- 使用短暂 ducking，而不是把整条音乐永久压得过低。
- 若人声本身不清晰，转到 `voice-and-audio-guide.md` 处理。

### 音效显得生硬

- 检查入点是否早于或晚于画面动作。
- 缩短尾巴、调整淡入淡出或换质感更接近的声音。
- 删除重复音效，给声音留出空间。

### 搜不到教程中的名称

- 保留教程原名和截图证据。
- 用同义词、英文词和声音特征搜索。
- 标注可能存在版本、地区或下架差异，不擅自替换成另一个确定名称。
