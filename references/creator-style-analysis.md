# 五分钟竖屏知识口播案例

## 文件职责

本文件只保留一个既有案例中独有的结构和风格观察，用于长口播方案参考。它不是
通用标准，不能覆盖用户当前要求，也不能把案例数值当成所有视频的推荐参数。

## 案例范围

- 类型：约 5 分钟的竖屏知识分享/技能教学。
- 画面：主播口播为主，穿插操作演示、图表和重点字幕。
- 风格：专业但亲和，视觉包装克制，依靠模块结构维持注意力。
- 适用参考：3-6 分钟、有明确知识模块的口播。
- 不适用：纯剧情、纯卡点、无口播产品片或用户要求极快节奏的短视频。

## 案例的核心结构

| 阶段 | 案例占比 | 内容功能 | 剪辑重点 |
|------|----------|----------|----------|
| 开头 | 约前 10% | 痛点、身份、价值承诺 | 快速进入主题，建立观看理由 |
| 主体 | 约中间 70% | 3-5 个知识模块 | 模块独立，例子与图示交替 |
| 总结 | 约后 10% | 回顾要点、强化结论 | 收束信息密度 |
| 行动引导 | 约最后 10% | 互动、关注或下期预告 | 简短明确，不重复多轮 |

比例只用于理解原案例。生成新方案时应根据文案结构重新分配。

## 模块化剪辑

### 开头

- 第一段先说用户能得到什么，再补背景。
- 痛点、问题或反常识结论作为首个视觉钩子。
- 主播近景与大字标题建立注意力，随后迅速回到稳定主画面。
- 价值承诺必须能在正文兑现，避免空悬念。

### 主体

每个模块内部使用相同的四步骨架：

1. 模块标题或过渡句。
2. 核心解释。
3. 示例、操作画面或图表。
4. 小结或连接下一个模块的钩子。

模块之间靠内容逻辑、标题和声音变化区分，不依赖花哨转场。

### 结尾

- 用 3-5 个短语回顾核心点，不重讲整段正文。
- 行动引导与内容价值相关，例如收藏步骤、评论问题或查看下一部分。
- 留出自然收音和画面停留，避免台词结束立刻黑屏。

## 节奏设计

该案例使用“稳定主节奏 + 局部加速”：

- 主体讲解保持稳定镜头，让观众理解信息。
- 新模块开始、关键结论和案例切入时短暂加快。
- 高信息密度段适当延长画面，配图表或分步字幕。
- 低信息密度段减少装饰，使用停顿和镜头距离变化。

不要机械套用“每 X 秒一切”。更可靠的切换依据是：

- 语义单元结束。
- 新概念或新案例进入。
- 主体指向屏幕、拿起物品或完成动作。
- 观众需要重置注意力，但内容仍需连贯。

## 注意力节点

五分钟口播容易在模块边界流失。案例中可复制的是节点功能，而非固定时间：

| 节点 | 作用 | 可用手法 |
|------|------|----------|
| 首个钩子 | 说明为什么值得看 | 问题、结果预览、反差画面 |
| 第一模块进入 | 从承诺转入交付 | 模块标题、录屏或示例 |
| 中段重启 | 防止注意力下滑 | 新问题、阶段结果、前后对比 |
| 接近结尾 | 告知剩余价值 | 总结预告、最后一个关键点 |
| 行动引导 | 让动作与内容连接 | 收藏步骤、评论选择、下期承接 |

## 视觉层级

案例保持四层，但同一时刻不必全部出现：

1. **主画面**：主播或操作演示，是信息主体。
2. **基础字幕**：保证口播可读，不抢主体。
3. **重点辅助**：关键词、步骤、数据、箭头或图表。
4. **包装效果**：转场、光效和贴纸，只在节点使用。

### 复用规则

- 字幕位置和基础样式保持一致。
- 每个模块使用相同标题层级和进入方式。
- 重点色控制在少量语义用途，例如结论、风险或步骤编号。
- 图表和录屏出现时，让主播画面让位，不要把所有信息挤在同一层。
- 复杂动效只服务理解或情绪，不作为默认填充。

## 声音层级

- 人声始终是第一层。
- BGM 提供连续情绪，不承担主要信息。
- 音效只标记模块切换、重点结论和交互反馈。
- 重要结论前可短暂压低 BGM 或留白，比叠加多个音效更有效。
- 具体资源查 `music-sfx-resource-library.md`，人声处理查
  `voice-and-audio-guide.md`。

## 可迁移方案

收到新文案时，按以下顺序使用本案例：

1. 判断内容是否确实适合 3-6 分钟模块化口播。
2. 从文案本身提取模块，不能先套“五模块”再硬拆。
3. 为每个模块指定一个理解辅助：录屏、案例、图表或关键词。
4. 在模块边界安排注意力重启，避免整段只有同步字幕。
5. 使用 `sentence-shot-template.md` 输出逐句方案。
6. 在文档末尾说明本次借用了哪些案例原则。

## 不应复制的内容

- 原案例的具体秒点、切换频率和模块数量。
- 未经当前素材验证的字体、音量、滤镜和导出参数。
- “每隔固定时间必须互动”之类机械规则。
- 与用户品牌、平台和受众不匹配的视觉包装。
- 无证据的完播率、互动率或复播率承诺。

## 使用检查

- [ ] 新文案具备清晰模块，而非为了套案例强行分段。
- [ ] 视觉辅助与当前讲解内容直接相关。
- [ ] 主体节奏稳定，但关键节点有变化。
- [ ] 声音设计没有盖过人声。
- [ ] 案例参数未被写成确定性通用规则。
