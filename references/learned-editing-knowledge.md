# 已确认剪辑知识库

## 用途

本文件只保存用户明确确认写入的新知识。基础常识留在其他参考文件，不在这里重复。

## 读取规则

1. 生成剪辑方案前，先按内容类型、平台、风格、关键词搜索本文件。
2. 只应用与当前文案相关的条目，不将所有已学知识强行塞入一个方案。
3. 优先级：用户当前要求 > 已确认知识 > 基础参考 > 临时推断。
4. 同类条目冲突时，优先选择平台、内容类型和风格更匹配且来源可靠性更高的条目；仍无法判断时列为备选，不擅自合并。
5. 待验证条目只用于提示可能性，不作为确定性参数。

## 条目格式

### K-YYYYMMDD-001：知识点名称

- **状态**：已确认 / 待验证 / 待验证冲突
- **分类**：画面 / 字幕 / 音效 / BGM / 镜头 / 节奏 / 结构 / 表演 / 工作流
- **适用场景**：内容类型、平台、时长、风格
- **检索关键词**：用逗号分隔
- **规则**：可直接应用的剪辑方法
- **参数**：教程明示的数值；未显示时写“未显示”
- **不适用**：不应使用该知识的情况
- **来源**：文件名 + 视频时间点 / 截图编号
- **证据类型**：画面明示 / 口播明示 / 视觉推断
- **来源可靠性**：已验证 / 教程单一来源 / 待验证
- **学习日期**：YYYY-MM-DD
